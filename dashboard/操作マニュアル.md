# OpenCCVoice for DVSwitch Web ダッシュボード 操作マニュアル

対象アプリ: dashboard/app.py（**V3.21** 以降）
サービス名: dvswitch-web（systemd ユニット: dvswitch-web.service）
アクセス URL: http://<ノードの IP アドレス>:8081/

---

## この文書について

本書は、OpenCCVoice for DVSwitch に同梱される Web ダッシュボード（dashboard/app.py）の**操作方法**をまとめたものです。構築・インストール手順は dashboard/README.md および dashboard/「how to install uninstall.md」を、Bot 本体の導入は ocv_dvs_jt/（JT版）・ocv_dvs_jtw/（JTW版）・ocv_dvs_vv/（VV版）・ocv_dvs_vvw/（VVW版）の各構築手順書を参照してください。

このダッシュボードは、ブラウザから次の設定・操作を GUI で行うためのものです。

- 各サービス（dvswitch-bot / analog_bridge / mmdvm_bridge など）の状態確認と再起動
- Bot の動作設定（受信時間フィルタ・時刻案内・定時メッセージ・ナイトモード・天気読み上げ〈JTW版〉 など）
- DVSwitch の ini ファイル設定（自局識別情報・ルーティング・位置情報 など）
- 読み上げ内容（コールサイン・地名・定時メッセージ）の編集と WAV 再生成
- カスタム音声（WAV 差し替え）の切り替え
- 任意の WAV のテスト送信

---

## 1. アクセスと画面構成

### 1-1. アクセス方法

ダッシュボードは 8081 番ポートで待ち受けます（0.0.0.0 にバインドされるため、同一 LAN 内の別 PC・スマートフォンからもアクセスできます）。ブラウザで次の URL を開きます。

```
http://<ノードの IP アドレス>:8081/
```

例: ノードの IP が 192.168.1.50 の場合は http://192.168.1.50:8081/ 。ノード自身で開く場合は http://localhost:8081/ でも構いません。

サービスが起動していない場合はページが開きません。その際はノード側で dvswitch-web サービスの状態を確認してください。

### 1-2. 画面の構成

画面上部にタイトル「OpenCCVoice for DVSwitch Web Dashboard」と版数（V3.2 など）が表示されます。以下、主なカードが縦に並びます。

- サービス状態 / サービス操作（各デーモンの稼働状況と再起動）
- テスト送信
- 読み上げ内容 — wav_source.json
- Bot 設定 — bot_config.json
- 天気読み上げ — JTW版（JTW版ノードのみ操作可能。それ以外のノードではグレーアウト表示）
- DVSwitch 設定 — ini ファイル（MMDVM_Bridge.ini / Analog_Bridge.ini）
- カスタム音声 — 差し替え

### 1-3. 「変更モード」について

各設定カードは、通常は**閲覧のみ**（保護された状態）で表示されます。値を書き換えるには、そのカードの「**変更モード**」を有効にしてから、フィールドを編集し「**保存**」を押します。編集をやめるときは「**取消**」で元に戻せます。この仕組みにより、誤操作で設定が書き換わるのを防いでいます。

---

## 2. サービス状態の確認と操作

ダッシュボードは一定間隔で /api/status を呼び出し、サービスの稼働状況と Bot の版数を画面に反映します。

サービス操作では、対象サービスに対して start / stop / restart を実行できます。主な対象は次のとおりです。

- **dvswitch-bot**: 自動音声応答の本体（dvswitch_bot.py）
- **analog_bridge**: 音声プロトコル変換ゲートウェイ
- **mmdvm_bridge**: TGIF ネットワークへの橋渡し
- （VV版のみ）**voicevox**: 音声合成エンジン

設定を変更・保存した後は、対象サービスの再起動で反映されます。とくに DVSwitch 設定（ini）を保存すると、dvswitch-bot・analog_bridge・mmdvm_bridge がまとめて再起動されます。

> 注意: 再起動中は数秒〜十数秒、音声応答が一時的に止まります。運用中の QSO がないタイミングで実施してください。

---

## 3. テスト送信

「テスト送信」カードでは、生成済みの WAV を1つ選び、単発で電波に送出して動作確認ができます。

1. プルダウンから送信したい WAV を選びます。
2. 「送信」を押します。
3. **送信が完了するまで画面は待機**します（「選択したWAVを単発送信します（完了まで画面は待機）」と表示されます）。完了するとメッセージが返ります。

実際に電波が出るため、送信は必要な範囲にとどめてください。

---

## 4. 読み上げ内容（wav_source.json）

「読み上げ内容 — wav_source.json」カードでは、アナウンスの**文言**を編集します。編集できるのは次の4項目です（太字＝入力で変えられる可変部分）。

1. **コールサイン**（名乗り）
2. **設置場所の地名**
3. **定時メッセージ1**（001）
4. **定時メッセージ2**（002）

コールサインは、DVSwitch 設定の自局識別情報から**自動生成**することもできます（「自動生成」）。

文言を変更したら「**保存して再生成（WAV作り直し）**」を押します。保存と同時に、対応する WAV が作り直されます。

> このノードが VOICEVOX 未導入（JT版など該当構成）の場合、一部の項目は「（このノードは VOICEVOX 未導入のため変更は不可）」と表示され、変更できないことがあります。既定のアナウンス（No.7〔アナウンス〕）で生成済みの WAV は「記録なし（既定 No.7〔アナウンス〕で生成されています）」と表示されます。

---

## 5. Bot 設定（bot_config.json）

「Bot 設定 — bot_config.json」カードでは、Bot の動作を細かく調整します。

### 5-1. 受信時間フィルタ

- **最小受信時間 (秒)**: これより短い受信は応答対象にしません（ノイズ・誤検出よけ）。
- **最大受信時間 / カーチャンク (秒)**: これ以内の短い送信を「カーチャンク」とみなします。

### 5-2. 時刻案内（時報）

- **時刻案内モード**:
  - `0`: 時刻案内しない
  - `1`: 毎正時のみ「○○時です」
  - `2`: 毎正時＋毎30分「○○時30分です」

### 5-3. 定時メッセージ（001/002 交互）

- **送出する分**: 定時メッセージを送る「分」を指定します。
- 定時メッセージは 001 と 002 を交互に送出します。

### 5-4. 送出音量

- **音量倍率**: 1.0＝等倍。0.0 超〜5.0 以下で指定します。

### 5-5. ナイトモード

- **ナイトモード有効（定時アナウンスを抑制）**: 夜間の定時アナウンスを止めます。
- **開始 N1 (0〜23)** / **終了 N2 (0〜23)**: 抑制する時間帯を指定します。

### 5-6. 天気読み上げ（JTW版）

「天気読み上げ — JTW版」カードで設定します。JTW版（voice_make.py を持つノード）でのみ操作でき、定時音声の後ろに「○○の天気は、晴れ、気温は 25 度です」を付けます。地名（○○）は §4「読み上げ内容」の地名と共通で、天気の取得元は Open-Meteo です。JTW版以外のノードでは、このカードはグレーアウトして「表示のみ」となり、保存しても bot_config.json の天気設定は書き換わりません。

- **天気読み上げを有効にする**: 天気付与の親スイッチです。オフのときは以下の項目は無視されます。
- **天気を付ける対象**（有効にすると表示）:
  - **時報（:00）・30分案内（:30）**: §5-2 の時刻案内に天気を付けます。実際に付けるには時刻案内モードを `1` 以上にしてください。
  - **定時メッセージ（001/002）**: §5-3 の定時メッセージに天気を付けます。実際に付けるには「送出する分」を 1 つ以上にしてください。
- **取得座標**:
  - **緯度（-90〜90）** / **経度（-180〜180）**: 天気を取得する地点です（例 35.2167 / 137.0333）。有効にするには入力が必須で、§6-3 の位置情報や MMDVM Info の緯度・経度が目安になります。
  - 座標欄を空欄のまま保存すると、以前入力した座標をそのまま維持します。

「天気読み上げを有効にする」を付けたまま保存する場合、天気が実際に付く先（時報系または定時メッセージ系）が 1 つも無いと保存できません（例: 対象を両方オフ、あるいは対象はオンでも時刻案内モードが `0`・送出する分が空、など）。また座標が未入力・範囲外でも保存できません。

変更後は「変更モード」→編集→「保存」。反映には dvswitch-bot の再起動が必要な項目があります。

---

## 6. DVSwitch 設定（ini ファイル）

「DVSwitch 設定 — ini ファイル」カードでは、MMDVM_Bridge.ini と Analog_Bridge.ini の主要項目を編集します。

### 6-1. 局識別情報（MMDVM_Bridge.ini）

- コールサイン
- **DMR ID（7桁）**
- **ESSID（2桁）**

> V1.94（JT版）／ V1.97vv（VV版）以降、Bot 本体は自局コールサイン・DMR ID を MMDVM_Bridge.ini / Analog_Bridge.ini から**起動時に自動取得**します。したがって、これらはソースを手修正する必要はなく、このカード（またはコマンドラインの dvs_config.sh）で設定します。

### 6-2. ルーティング（Analog_Bridge.ini）

- **送信 TG（txTg）**
- **周波数**

### 6-3. 位置情報

- **Latitude（緯度）** / **Longitude（経度）**
- **Height（高さ m）**
- **Location（設置場所）**
- その他の付随項目

これらの ini 設定を「保存」すると、dvswitch-bot・analog_bridge・mmdvm_bridge がまとめて再起動され、変更が反映されます。

---

## 7. カスタム音声（差し替え）

「カスタム音声 — 差し替え」カードでは、既定の合成音声の代わりに、あらかじめ用意した WAV を使うよう切り替えます。

- **intro（名乗り）に cstm_intro.wav を使う**
- **001 に cstm_001.wav を使う**
- **002 に cstm_002.wav を使う**

チェックを入れて「保存」すると、該当箇所で対応するカスタム WAV が使われます。カスタム WAV は所定の場所にあらかじめ配置しておく必要があります（配置方法は構築手順書を参照）。

---

## 8. 保存と反映の流れ（まとめ）

1. 変更したいカードの「**変更モード**」を有効にする。
2. フィールドを編集する。
3. カードの「**保存**」（読み上げ内容は「保存して再生成」）を押す。
4. 反映のためにサービスを再起動する（ini 設定の保存では自動的にまとめて再起動）。
5. 「テスト送信」で実際の音声を確認する。

編集を破棄したいときは「**取消**」で元の値に戻せます。

---

## 9. 困ったときは

- **画面が開かない**: dvswitch-web サービスが起動しているか、ポート 8081 がファイアウォールで塞がれていないかを確認します。
- **保存したのに反映されない**: 対象サービスの再起動を行ってください（ini 設定以外は手動再起動が必要な場合があります）。
- **読み上げ内容が変更できない**: VOICEVOX 未導入のノードでは一部項目が変更不可になります。
- **状態表示が「停止」のまま**: 依存する DVSwitch 各サービス（analog_bridge / mmdvm_bridge）や設定値を確認してください。
