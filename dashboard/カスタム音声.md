# カスタム音声（cstm）簡易マニュアル

OpenCCVoice for DVSwitch — 標準音声を自前の音声に差し替える手順

対象バージョン: dvswitch_bot.py V1.73 以降 / app.py（ダッシュボード）V2.83 以降 / bot_setup.py（cstm 対応版）以降

---

## 1. これは何か

bot が送出する音声のうち、次の3つを「自分で用意した音声ファイル」に差し替えられる機能です。

| 差し替え対象 | 標準ファイル | カスタムファイル | 使われる場面 |
|---|---|---|---|
| intro（名乗り） | `fixed_intro.wav` | `cstm_intro.wav` | カーチャンク応答・起動アナウンス・ナイトアナウンスの前置き |
| 定時メッセージ1 | `001.wav` | `cstm_001.wav` | 定時メッセージ（001/002 交互再生の片方） |
| 定時メッセージ2 | `002.wav` | `cstm_002.wav` | 定時メッセージ（001/002 交互再生の片方） |

3つは**個別に**ON/OFF できます（intro だけカスタム、001 は標準、のような組み合わせが可能）。

intro をカスタムにすると、それを使う3か所すべて（カーチャンク応答・起動・ナイト）に同時に効きます。intro はこれら共通の前置き音声のためです。

時報イントロ（`time_intro.wav`）や outro 類はカスタム差し替えの対象外です。

---

## 2. ファイルの置き場所と名前

カスタムファイルは、標準ファイルと同じ場所（`/opt/dvswitch_bot/` 直下）に、決められた名前で置きます。

```
/opt/dvswitch_bot/
├── fixed_intro.wav   ← 標準（create_wav.sh が作る）
├── 001.wav           ← 標準
├── 002.wav           ← 標準
├── cstm_intro.wav    ← カスタム（自分で用意）★
├── cstm_001.wav      ← カスタム（自分で用意）★
└── cstm_002.wav      ← カスタム（自分で用意）★
```

ファイル名は**完全に固定**です。大文字小文字も含めて、上記のとおりにしてください。名前が1文字でも違うと「ファイルが無い」と判断され、標準音声で鳴ります。

---

## 3. 音声ファイルの形式（重要）

bot は WAV をそのまま無線に流すため、形式が合っていないと音が壊れます。次の形式で用意してください。

| 項目 | 値 |
|---|---|
| 形式 | WAV（非圧縮 PCM） |
| サンプリングレート | 8000 Hz |
| チャンネル | モノラル（1ch） |
| ビット深度 | 16 bit |

手元の音声（mp3 やステレオの wav など）を SoX で変換する例:

```bash
sox 元音声.wav -r 8000 -c 1 -b 16 cstm_intro.wav
```

mp3 から作る場合（ffmpeg で一度 wav にしてから SoX）:

```bash
ffmpeg -i 元音声.mp3 tmp.wav
sox tmp.wav -r 8000 -c 1 -b 16 cstm_intro.wav
```

形式が正しいかは次で確認できます（`8000 Hz` `Channels: 1` `Precision: 16-bit` になっていればOK）。

```bash
soxi cstm_intro.wav
```

## 4. ファイルを置く手順

作ったカスタムファイルを所定の場所にコピーします。書き込み保護された場所なので `sudo` を使います。

```bash
sudo cp cstm_intro.wav /opt/dvswitch_bot/cstm_intro.wav
sudo cp cstm_001.wav   /opt/dvswitch_bot/cstm_001.wav
sudo cp cstm_002.wav   /opt/dvswitch_bot/cstm_002.wav
```

置けたか確認:

```bash
ls -l /opt/dvswitch_bot/cstm_*.wav
```

差し替えたい分だけ置けば十分です（intro だけ使うなら `cstm_intro.wav` だけでOK）。

---

## 5. 有効化する（2通り）

ファイルを置いただけでは標準のままです。「カスタムを使う」設定を ON にする必要があります。方法は2つ、どちらでも同じ結果です。

### 方法A: ダッシュボード（おすすめ・簡単）

1. ブラウザで `http://<ラズパイのIP>:8081/` を開く
2. 右上の「変更モード」を押す
3. 中央の「カスタム音声 — 差し替え」カードで、使いたい項目にチェックを入れる
4. 「保存」を押す（自動でサービスが再起動され反映されます）

### 方法B: 対話設定ツール（bot_setup.py）

```bash
sudo python3 /opt/dvswitch_bot/bin/bot_setup.py
```

対話の中盤に「カスタム音声（差し替え）」の質問が出るので、使いたいものに `y` と答えます。最後まで進めて保存したら、bot を再起動します。

```bash
sudo systemctl restart dvswitch-bot
```

---

## 6. 反映を確認する

bot のログに、現在どの音声が選ばれているかが出ます。

```bash
journalctl -u dvswitch-bot -n 50 --no-pager | grep -i Voice
```

表示の見方:

```
Voice intro : カスタム (cstm_intro.wav)   ← カスタムが有効＆ファイルあり
Voice 001   : 標準 (001.wav)              ← 標準のまま
Voice 002   : カスタム指定だが cstm_002.wav が無い → 標準 (002.wav) にフォールバック
```

3行目のように「カスタム指定だがファイルが無い」場合は、自動的に標準で鳴ります（後述）。

---

## 7. 安全の仕組み（フォールバック）

カスタムを ON にしても、対応するファイルが見つからなければ**自動的に標準音声で鳴ります**。送信が止まったり無音になったりはしません。

判定は送出のたびに行われるため、後からファイルを置けば、次の送出から自動でカスタムに切り替わります（この場合、bot 再起動は不要です。ただし設定の ON/OFF を変えたときは再起動が要ります）。

つまり、

- ファイルを置く前に ON にしてしまっても安全（標準で鳴るだけ）
- ファイルを後から置けば、再起動なしで次回からカスタムに切り替わる

---

## 8. 標準に戻す

カスタムをやめたいときは、有効化の操作（方法A または B）で**チェックを外す（または `n` と答える）**だけです。カスタムファイル自体は消さなくても、設定が OFF なら標準が鳴ります。

---

## 9. つまずきポイント早見表

| 症状 | 原因 | 対処 |
|---|---|---|
| カスタムにしたのに標準のまま | ファイル名が違う / 置き場所が違う | `ls /opt/dvswitch_bot/cstm_*.wav` で名前と場所を確認 |
| 音が割れる・ケロる | 形式が 8kHz/モノラル/16bit でない | `soxi` で確認し、SoX で変換し直す |
| 設定したのに変わらない | 設定変更後に再起動していない | ダッシュボードの保存（自動再起動）か `systemctl restart dvswitch-bot` |
| ログに「フォールバック」と出る | カスタム ON だがファイルが無い | ファイルを置く（置けば再起動なしで反映） |

---

## 10. まとめ（最短手順）

1. 8kHz・モノラル・16bit の WAV を作る → `cstm_intro.wav` 等にリネーム
2. `sudo cp` で `/opt/dvswitch_bot/` に置く
3. ダッシュボードの「カスタム音声」でチェック → 保存
4. ログで `カスタム (cstm_xxx.wav)` を確認

以上です。
