# ocv_dvs_jtw — Open JTalk 版＋天気読み上げ（JTW版）

DVSwitch 自動音声応答システムの **JTW版**（JT版 + 時報への当地天気読み上げ）スクリプト群です。
[`../ocv_dvs_jt/`](../ocv_dvs_jt/)（JT版 V1.95）を母体に、VV版 V2.0vv で確定した天気読み上げ仕様を移植した系統です。Raspberry Pi ノード用（Raspberry Pi OS Bookworm、Open JTalk + SoX）。

> **位置づけ:** JT版は安定版としてそのまま維持し、天気読み上げの実波検証は本フォルダ（JTW版）で行います。第三者局が参照する JT版の取得 URL には影響しません。

## JT版からの追加機能（V2.00jtw）

毎正時の時報に続けて、Open-Meteo API（キー不要・追加インストール不要）から取得した当地の天気を読み上げます。

```
正時2分前   天気コード＋気温を取得
    ↓      「こちらは、〜。12時です。続いて当地の天気は、晴れ、気温は25度です」
            をイントロ込みの1本ものWAVとして事前生成
正時発火    完成WAVを再生するだけ（Open JTalk 合成ゼロ＝Pi の合成遅延を完全吸収）
```

- **三段フォールバック**（時報は絶対に落とさない）: ①事前生成WAV → ②取得済みテキストからその場合成 → ③従来の「N時です」のみ
- 鮮度15分超の事前生成WAVは使わず破棄。取得失敗時は天気だけ黙って省略し、時報は定刻
- ナイトモード・:30 の30分案内は従来どおり（天気が付くのは :00 のみ）

## 設定（bot_config.json の任意キー）

| キー | 内容 |
|---|---|
| `WEATHER_ENABLED` | 天気読み上げの有効/無効（true/false）。未設定なら OFF＝完全に従来動作 |
| `WEATHER_LATITUDE` | 取得座標の緯度（有効時は必須。例 35.2167） |
| `WEATHER_LONGITUDE` | 取得座標の経度（有効時は必須。例 137.0333） |
| `WEATHER_HOURS` | 天気を読む正時の配列（例 `[7, 12, 18]`）。省略時は全時刻 |

`bot_setup.py`（JTW版）の対話でも設定できます。`TIME_SIGNAL_MODE=0`（時報なし）との併用は本体が起動を拒否します。

## 主なファイル

- `dvswitch_bot.py` — **V2.01jtw** 常駐 bot（JT V1.95 + 天気読み上げ）
- `bot_setup.py` — **JTW版 V2.02jtw**（WEATHER キーの対話設定・引き継ぎ対応、座標初期値を `MMDVM_Bridge.ini` から補完。旧版で設定を作り直すと天気キーが消えるため、JTW ノードでは必ずこちらを使うこと）
- `create_wav.sh` — JT版と同一（固定WAVに変更なし）
- `dvs_config.sh` / `test_send.py` — JT版・VV版と共通（同一内容）

## ダッシュボードについての注意

Web ダッシュボード（リポジトリ直下の [`dashboard/app.py`](../dashboard/app.py)）は JT版・VV版と共用で、**現時点で WEATHER キーには未対応**です。表示は問題ありませんが、**ダッシュボードから設定を保存すると天気キーが失われる可能性があるため、JTW ノードの設定変更は `bot_setup.py`（JTW版）で行ってください。** ダッシュボードの対応は実波検証後に別途行います。
