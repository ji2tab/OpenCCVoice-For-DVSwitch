# ocv_dvs_jtw — Open JTalk 版＋天気読み上げ（JTW版）

DVSwitch 自動音声応答システムの **JTW版**（JT版 + 定時音声への当地天気読み上げ）スクリプト群です。
[`../ocv_dvs_jt/`](../ocv_dvs_jt/)（JT版 V1.95）を母体に、天気読み上げ機能を追加した系統です。Raspberry Pi / x86_64 いずれのノードでも動作（Open JTalk + SoX）。

> **位置づけ:** JT版は安定版としてそのまま維持し、天気読み上げの開発・実波検証は本フォルダ（JTW版）で行います。第三者局が参照する JT版の取得 URL には影響しません。

## 追加機能（V2.03jtw〜）— 定時音声への当地天気

毎正時の時報だけでなく、**すべての定時音声（時報 :00 / 30分案内 :30 / 定時メッセージ 001・002）の後ろ**に、Open-Meteo API（キー不要・追加インストール不要）から取得した当地の天気を読み上げます。

```
「12時です。○○の天気は、晴れ、気温は25度です」     ← 時報
「12時30分です。○○の天気は、晴れ、気温は25度です」  ← 30分案内
「（001の内容）。○○の天気は、晴れ、気温は25度です」  ← 定時メッセージ
```

地名（○○）は `wav_source.json` の `location`（`create_wav.sh` でイントロに設定する地名）を使うため、イントロと天気で必ず一致します。

### アーキテクチャ — bot と voice_make.py（vmp）の分離

V2.03jtw で、天気の取得・合成を **`voice_make.py`（略称 vmp）** という独立プログラムに分離しました。bot 本体は天気を一切知らず、「定時音声を再生するだけ」に専念します。

```
bot（判定・号令・再生）              voice_make.py（vmp / 生成）
  発火の約2分前 ──「これを作れ」──▶  天気を取得し「本体音声＋天気」を
                                      1本の WAV（スロット）に焼く
  発火時 ◀── スロットを再生 ──────    （ワンショット起動・常駐しない）
```

- **時報の正確さを維持**: 発火2分前に事前生成し、発火時は再生のみ（合成ゼロ＝遅延ゼロ）。Open JTalk の合成時間による遅れが出ない。
- **フォールバック（時報を絶対に落とさない）**: 天気の取得・合成に失敗しても、vmp は本体音声（「N時です」等）だけはスロットに必ず書く → 回線断でも時報は定刻に流れ、天気だけ欠ける。
- **音量（TX_GAIN）は送信時制御**: vmp は素の音量でスロットを作り、bot が送出の瞬間に TX_GAIN をかける。音量変更でスロットを作り直す必要がなく、カーチャンク応答と音量制御が一貫する。
- **ナイトモード中**: カーチャンク応答を除き送信しない（時報・30分・001/002 は bot が号令しないため生成もされない）。ナイトモード突入告知は従来どおり bot が生成（天気なし）。

## 設定（bot_config.json の任意キー）

| キー | 内容 |
|---|---|
| `WEATHER_ENABLED` | 天気読み上げの有効/無効（true/false）。未設定なら OFF＝完全に従来動作 |
| `WEATHER_LATITUDE` | 取得座標の緯度（有効時は必須。例 35.2167） |
| `WEATHER_LONGITUDE` | 取得座標の経度（有効時は必須。例 137.0333） |

`bot_setup.py`（JTW版）の対話で設定できます。座標が未設定なら `MMDVM_Bridge.ini` の `[Info]` から初期値を提示します。時報も定時メッセージも無い設定（`TIME_SIGNAL_MODE=0` かつ `ANNOUNCE_FREQ=0`）との併用は、天気を付ける相手が無いため起動を拒否します。

> **地名の変更:** 天気文の地名は `create_wav.sh` で設定する地名（`wav_source.json/location`）と共通です。地名を変えたいときは `create_wav.sh` で地名を設定し直します（イントロも天気も一度に変わります）。

## 主なファイル

- `dvswitch_bot.py` — **V2.03jtw** 常駐 bot（判定・2分前号令・スロット再生。天気は vmp に分離）
- `voice_make.py` — **V1.01vmp** 天気音声生成ツール（ワンショット。取得・合成・地名・1本化を担う）
- `bot_setup.py` — **V2.03jtw**（WEATHER キーの対話設定、座標初期値を `MMDVM_Bridge.ini` から補完）
- `create_wav.sh` — 固定WAV生成（イントロの地名＝`location` を設定。JT版と同一）
- `dvs_config.sh` / `test_send.py` — JT版・VV版と共通（同一内容）

## ダッシュボードについての注意

Web ダッシュボード（[`../dashboard/app.py`](../dashboard/app.py)）は JT版・VV版と共用で、**現時点で WEATHER キーには未対応**です。**ダッシュボードから設定を保存すると天気キーが失われる可能性があるため、JTW ノードの設定変更は `bot_setup.py`（JTW版）で行ってください。** ダッシュボードの対応は実波検証後に別途行います。
