# Pi-Star / WPSD DVSwitch 音声カーチャンクボット 実装手順書（dvswitch_bot158.py V1.58 対応）

実際にSSH（ターミナル）にコピー＆ペーストして実行できるコマンド群をまとめた、実践的な実装手順書です。

Pi-Star / WPSD環境のコンソール（SSH）から順番に実行してください。

---

## 1. システムの準備と書き込み可能モードへの移行

まずはファイルシステムを書き込み可能にし、必要なパッケージ（Open JTalk, SoX, unzip）をインストールします。

```bash
# 書き込み可能モードへ変更
rpi-rw

# パッケージリストの更新と必要なソフトのインストール
sudo apt-get update
sudo apt-get install -y open-jtalk open-jtalk-mecab-naist-jdic sox unzip
```

---

## 2. 高品質音声モデル（メイ）の導入

MMDAgentの公式サイトからデータをダウンロードし、所定のディレクトリに配置します。

```bash
# 一時ディレクトリに移動
cd /tmp

# MMDAgentのサンプルデータをダウンロード
wget -L --content-disposition https://sourceforge.net/projects/mmdagent/files/MMDAgent_Example/MMDAgent_Example-1.8/MMDAgent_Example-1.8.zip
# ※ SourceForge はリダイレクトが発生するため -L オプションが必要です

# 解凍して音声モデルを取り出す
unzip MMDAgent_Example-1.8.zip
sudo mkdir -p /usr/share/hts-voice/mei
sudo cp MMDAgent_Example-1.8/Voice/mei/mei_normal.htsvoice /usr/share/hts-voice/mei/

# ゴミ掃除
rm -rf MMDAgent_Example-1.8.zip MMDAgent_Example-1.8
```

---

## 3. DVSwitch (Analog_Bridge) の設定変更と再起動

PythonスクリプトからのUDP音声パケットを受け入れるため、設定ファイルを編集します。

```bash
# 設定ファイルをエディタ(nano)で開く
sudo nano /opt/Analog_Bridge/Analog_Bridge.ini
```

### nanoエディタでの編集内容

`[USRP]` セクションを探し、以下のように書き換えます（※自己ループと致命的エラーを回避します）。

```ini
[USRP]
rxPort = 51000
txPort = 51001
;jitterQueueSize = 30  ← 先頭に「;」をつけてコメントアウト
;pcmBufferMS = 200     ← 先頭に「;」をつけてコメントアウト
```

> *Ctrl+O → Enter で保存し、Ctrl+X で閉じます*

```bash
# 変更を反映してAnalog_Bridgeを再起動
sudo systemctl restart Analog_Bridge
```

## 4. システムディレクトリの作成と固定WAVの生成

V1.58 では以下の5ファイルが必要です。詳細な作成コマンドは **「音声ソース作成.md」** を参照してください。
ここでは最小限の作成例を示します（出力フォーマットは共通で 8000Hz / モノラル / 16bit PCM）。

```bash
# ボット用のディレクトリを作成
sudo mkdir -p /opt/dvswitch_bot
sudo chown pi-star:pi-star /opt/dvswitch_bot
cd /opt/dvswitch_bot

# 1. fixed_intro.wav（カーチャンク応答イントロ）
echo "こちらは、ジェイジェイツーワイワイケー、おわりあさひ ディーエムアール デジピーターです。" | open_jtalk -x /var/lib/mecab/dic/open-jtalk/naist-jdic -m /usr/share/hts-voice/mei/mei_normal.htsvoice -ow /tmp/tmp_intro.wav
sox /tmp/tmp_intro.wav -r 8000 -c 1 -b 16 /opt/dvswitch_bot/fixed_intro.wav

# 2. fixed_outro.wav（カーチャンク応答アウトロ）
echo "カーチャンクです。" | open_jtalk -x /var/lib/mecab/dic/open-jtalk/naist-jdic -m /usr/share/hts-voice/mei/mei_normal.htsvoice -ow /tmp/tmp_outro.wav
sox /tmp/tmp_outro.wav -r 8000 -c 1 -b 16 /opt/dvswitch_bot/fixed_outro.wav

# 3. time_intro.wav（時報イントロ）
echo "こちらは、ジェイジェイツーワイワイケー、" | open_jtalk -x /var/lib/mecab/dic/open-jtalk/naist-jdic -m /usr/share/hts-voice/mei/mei_normal.htsvoice -ow /tmp/tmp_time.wav
sox /tmp/tmp_time.wav -r 8000 -c 1 -b 16 /opt/dvswitch_bot/time_intro.wav silence 1 0.1 1% reverse silence 1 0.1 1% reverse

# 4. 001.wav（定時メッセージ1）
echo "こちらは、ジェイジェイツーワイワイケー、尾張旭、DMR、デジピーターです。" | open_jtalk -x /var/lib/mecab/dic/open-jtalk/naist-jdic -m /usr/share/hts-voice/mei/mei_normal.htsvoice -ow /tmp/tmp_001.wav
sox /tmp/tmp_001.wav -r 8000 -c 1 -b 16 /opt/dvswitch_bot/001.wav silence 1 0.1 1% reverse silence 1 0.1 1% reverse

# 5. 002.wav（定時メッセージ2）
echo "こちらは、ジェイジェイツーワイワイケー、尾張旭、DMR、デジピーターです。定時アナウンスです。" | open_jtalk -x /var/lib/mecab/dic/open-jtalk/naist-jdic -m /usr/share/hts-voice/mei/mei_normal.htsvoice -ow /tmp/tmp_002.wav
sox /tmp/tmp_002.wav -r 8000 -c 1 -b 16 /opt/dvswitch_bot/002.wav silence 1 0.1 1% reverse silence 1 0.1 1% reverse

# 作成確認
ls -la /opt/dvswitch_bot/
```

> **注意:** `time_outro.wav` は V1.58 では不要です（動的合成に統合済み）。
> 読み上げ内容の詳細カスタマイズは **「音声ソース作成.md」** を参照してください。

## 5. メインプログラムの配置と起動確認

`dvswitch_bot158.py` をホームディレクトリに配置し、動作確認後にシステムを保護状態に戻します。

```bash
# dvswitch_bot158.py をホームディレクトリにコピー（Git / scp / USB 等で配置）
cp /path/to/dvswitch_bot158.py ~/dvswitch_bot158.py

# 実行権限を付与
chmod +x ~/dvswitch_bot158.py

# システムを読み取り専用（安全な状態）に戻す
rpi-ro
```

### 手動での起動テスト用コマンド

動作テストを行う場合は、以下のコマンドで直接起動します。起動時に対話設定が表示されます。

```bash
python3 ~/dvswitch_bot158.py
```
